# 農園の用語集と判断ルール（言葉・全担当が最初に読む）

録音の文字起こしは話し言葉なので、下の対応で場所や意味を読み替える。
ここに無い言い方が出たら推測で決めず「要確認」にして、記録係に聞いたうえでここに追加する。

## 場所（ハウス）
| 発言 | 指すもの |
|---|---|
| ハウス1 / 1 | 1号ハウス |
| ハウス2 / 2 | 2号ハウス |
| ハウス3 / 3 | 3号ハウス |
| ハウス4 / 4 | 4号ハウス |
| ハウス5 / 5 | 5号ハウス（「ハウス5」の後ろが切れていたため5号と解釈。要確認） |
| 5連 | 5連ハウス（5号とは別の場所として扱う） |
| 2連 | 2連ハウス（2号とは別の場所として扱う） |
| 丘 | 丘ハウス |
| 坂 | 坂ハウス |

- 「5連」「2連」「丘」「坂」が各号ハウスのどれに当たるか（位置関係）は未確認。

## 判断ルール：「迷ったら取る／取らない」
収穫のとき、取るか迷う実が出る。迷ったときの基本の考え方:

| 発言 | 意味 | 読み取れる状況 |
|---|---|---|
| 迷ったら取らない | 契約出荷の荷物が少なく、ナスが少ないときの考え方。小さい実や迷う実は取らずに残す | **ハウス内のナスの収穫量が減っている**と判断する |
| 迷ったら取る | 契約出荷の荷物（在庫）が潤沢なとき。株への負荷（録音では「機能負荷」。要確認）を下げるため、迷う実は取ってよい | 収穫量・在庫に余裕がある |

- 「迷ったら取らない」が出たら、議事録の分析に「収穫量が減っている兆候」として必ず書く。
- どちらの発言が出たか、どのハウスの話かを、日程表の作業に必ず付ける。

## 人名と担当の割り振り
- 録音の中に個人名が出たら、その人が何をするか（場所・作業・期日）を「担当の割り振り」に表でまとめる。
- 名前が出ていないときは「未定」と書く。名前を推測で補わない。
