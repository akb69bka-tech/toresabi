🌾 圃場・作物マスタ

圃場（畑・ハウス）と栽培作物を登録します。音声照会の「場所」「作物」の基準になります。

📋 作業記録・予定

水やり・施肥・防除・播種・定植・整枝・収穫などの作業を記録します。

📈 生育・環境記録

草丈・生育ステージ・気温・湿度などを記録します。

🧺 収穫・出荷記録

収穫量・等級・出荷先を記録します。音声で「収穫量」「収量」を集計できます。

🧴 資材・農薬・肥料

農薬・肥料・資材の使用を記録します。防除履歴として音声で引き出せます。

☁️ クラウド同期

同じワークスペースIDとFirebase設定を入力した端末どうしで、データがリアルタイムに共有されます。複数人・複数端末での利用に対応します。

未接続（ローカル保存）

※設定はこの端末にのみ保存され、コードには残りません。接続すると、このワークスペースのクラウド上のデータが表示されます。空の場合は「今のデータを送信」で移行できます。

Firebaseの準備手順（初回のみ・約5分）
  1. Firebaseコンソールを開き、Googleアカウントでログイン → 「プロジェクトを追加」
  2. 左メニュー「構築 → Firestore Database」→「データベースを作成」→ ロケーションは asia-northeast1（東京） 推奨 →「テストモードで開始」
  3. 左上⚙️「プロジェクトの設定」→ 下部「マイアプリ」で </>（ウェブ）を追加 → 表示された firebaseConfig = {…} をコピーし、上の①へ貼り付け
  4. ②のワークスペースIDを決めて（例：会社名＋年）、共有する全員が同じ値を入力
  5. 「接続する」→ 既存データがあれば「今のデータを送信」で移行
セキュリティ（推奨）： テストモードは約30日で読み書きが止まります。継続利用するには、Firestoreの「ルール」を下記に更新し、①のワークスペースIDを推測されにくい文字列にしてください。 
rules_version = '2';
service { cloud.firestore {
  match /databases/{db}/documents {
    match /workspaces/{ws}/{coll}/{doc} {
      allow read, write: if true;   // 社内限定運用向けの簡易ルール
    }
  }
}}
より厳密に運用する場合は「Authentication → 匿名」を有効化のうえ if request.auth != null をご利用ください（本アプリは匿名ログインを自動で試みます）。
