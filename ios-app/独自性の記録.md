## 1. 結論

- **作るときに参考にしたアプリは、記録の上ではありません。** 開発の全履歴（53件の変更）と、アプリの全ファイルに、他社アプリの名前・画面・文章・画像を取りこんだ跡はありませんでした。
- 他社アプリの名前が出てくるのは、**公開の直前（2026年10月20日）に「似ているものがないか」を調べた文書**（`類似アプリの調査と差別化.md`）だけです。この調査は作った後に行い、重なった言い回しを**変える**ために使いました。

## 4. 似たアプリの調査（2026年10月22日・追加調査）

前回（10月20日）の調査に加えて、次を調べました。

### 4-1. 名前

| 調べたもの | 結果 |

| 「ご飯帖」「ごはん帖」のアプリ | 見つからず。ヒットしたのはこのアプリ自身の GitHub だけ。近い名前は「ごはんメモ」「ゴチログ（ごはん日記）」「ごはんクエスト」「ごはんガチャ」で、どれも食事の記録や外食の決定用で、表記も用途も違う |

| 商標データベース（J-PlatPat・USPTO・EUIPO） | この環境からは直接検索できませんでした（**わかりません**）。出願の前に必ず J-PlatPat で確認してください |

### 4-2. 機能と見せ方

| 似ている点 | 似たアプリ | 判断 |
| --- | --- | --- |
| 主菜・副菜・汁ものをまとめて自動提案 | クラシル、デリッシュキッチン、me:new、YouCam AI チャット | この分野で一般的な機能。特定のアプリの特徴ではない |
| 冷蔵庫の材料から料理を探す | クックパッド、pecco、AIレシピ管理（Riafy）、クラシル | 同上 |
| 1週間の献立と買い物リスト | 今日の献立、meek、Plan Meals、WeeknightChef、海外の多数 | 同上 |
| 世界の料理 | Meal Planner – Eating well、Cookly（世界のレシピを料理名・材料・料理の種類で検索） | 「世界のレシピを集めた検索」はある。ただし**国を選ぶと、その国の家庭料理と言語で毎日の献立が組まれる**形は見つからず |
| お膳の図で献立を見せる | 見つからず（一汁三菜の配膳の解説記事はあるが、アプリの画面としては確認できず） | このアプリの最も固有な部分 |

結論: 機能の一つひとつは多くのアプリと共通していますが、**組み合わせ（お膳の図＋作った記録で同じ料理を避ける＋21の国・地域の家庭料理と17言語＋アカウント不要で端末内に保存）と、名前・絵・文章は独自**です。アイデアや機能そのものは著作権で守られないのが一般的で、模倣かどうかが問題になるのは、名前・ロゴ・画面のデザイン・文章・絵が似ている場合です。そのどれも、似たものは見つかりませんでした。

### 4-3. 調べ方と限界

- ウェブ検索（日本語・英語）と、App Store の掲載ページの検索結果で確認しました。
- App Store の中を全件検索することはできません。申請の前に、iPhone の App Store で「ご飯帖」「ごはん帖」「献立 お膳」「Gohancho」と検索して、同じ名前・似たアイコンがないかを目で確かめてください。
- 調査は 2026年10月22日時点です。公開後に似たアプリが出てきた場合、こちらが先に作った証拠として 3 の記録が役に立ちます。

## 5. 最も鋭い疑いと、その答え

| 疑い | 答え |
| --- | --- |
| 「AI が学習したデータの中に他社アプリがあったはずで、AI の出力は結局どこかの模倣では」 | AI の学習データの中身は、利用者には確かめられません（**わかりません**）。ただし、問題になるのは「出来上がったものが特定の作品と似ているか」です。名前・絵・文章・画面を調べた範囲では、特定のアプリに似たものは見つかっていません。文化庁の整理でも、生成物が既存の作品に似ていて、しかもそれに依拠している場合に侵害が問題になるとされています |
| 「公開直前に他社アプリを調べている。それを見て直したのなら参考にしたのでは」 | 調べたのは公開の直前で、目的は**重なりを避けること**でした。実際に変えたのはキャッチコピーと英語の説明文だけで、変えた先はむしろ他社と違う表現です（「今日のお膳、できました。」など）。調べる前の版も履歴に残っていて、比べられます |
| 「主菜・副菜・汁ものの提案は me:new やクラシルと同じ」 | 献立を主菜・副菜・汁もので組むのは和食の一般的な考え方（一汁三菜）で、農林水産省も解説しています。どのアプリの独自のものでもありません |

python3 -c "import json,collections;m=json.load(open('gohancho/img/dish/manifest.json'))['items'];print(len(m),collections.Counter(v.get('via') for v in m.values()))"

# ファイルが記録した日から変わっていないこと
