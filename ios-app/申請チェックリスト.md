# App Store 申請チェックリスト（ごはん帖）

上から順に進めれば、審査に出すところまで行けます。**［自分］** はあなたにしかできない作業、**［済］** はこちらで準備済みのものです。

---

## 0. 準備済みのもの

- ［済］料理の絵を ChatGPT で作る道具（`tools/illustrations/`）とアプリ側の表示
- ［済］アプリ本体（`gohancho/`）: 123品のレシピ、献立・買い物メモ・LINE 送信・通知・課金のしくみ
- ［済］iPhone アプリの設定（`ios-app/capacitor.config.json`）と、準備を一度に行うスクリプト（`ios-app/scripts/setup-ios.sh`）
- ［済］アイコン 1024px と起動画面（`ios-app/assets/`）
- ［済］スクリーンショット 6.9インチ・6.5インチ 各6枚（`ios-app/appstore/screenshots/`）
- ［済］App Store に入力する文章一式（`ios-app/appstore/metadata.md`）
- ［済］プライバシーポリシー・サポートページの下書き（`gohancho/privacy.html`・`gohancho/support.html`）

## 1. お金とアカウント（合計 1〜2日。審査待ちの時間を含む）

- [ ] ［自分］**Apple Developer Program に登録**（年99米ドル。個人で可）: https://developer.apple.com/jp/programs/
- [ ] ［自分］App Store Connect の「契約/税金/口座情報」で **有料 App 契約** に同意し、銀行口座と税の情報を入れる（これがないと課金を売れません）
- [ ] ［自分］**App Store Small Business Program** に申し込む（手数料が15%になる）: https://developer.apple.com/jp/app-store/small-business-program/
- [ ] ［自分］**RevenueCat** に登録（無料枠あり）: https://www.revenuecat.com/

## 3. Mac で iPhone アプリを作る（初回 30〜60分）

- [ ] ［自分］Mac に **Xcode**（App Store）と **Node.js LTS**（https://nodejs.org/ ）を入れる
- [ ] ［自分］ターミナルで:

```bash
cd ~/Documents/toresabi && git pull
cd ios-app && npm run setup
```

`npm run setup` が、部品の取りこみ・iOS プロジェクト作成・アイコン生成・審査に必要な設定（カメラの説明文、暗号化の申告、iPhone 専用化）・Xcode を開くところまで自動で行います。

## 4. Xcode での設定（10分）

- [ ] ［自分］左の「App」→「Signing & Capabilities」→ **Team** で自分の開発者アカウントを選ぶ
- [ ] ［自分］同じ画面の「+ Capability」→ **In-App Purchase** を追加
- [ ] ［自分］「General」→ Supported Destinations が **iPhone だけ** になっていることを確認（iPad があれば削除）
- [ ] ［自分］「General」→ Version を `1.1.0`、Build を `1` にする
- [ ] ［自分］iPhone をつないで ▶ で動かし、献立・LINE 送信・写真登録・通知（設定 → 毎日のお知らせ）を試す

## 5. App Store Connect で課金を作る（30分）

- [ ] ［自分］App Store Connect →「マイ App」→ ＋ 新規 App（名前・バンドル ID・SKU は `metadata.md` の表のとおり）
- [ ] ［自分］「サブスクリプション」でグループ「ごはん帖プラス」を作り、月額・年額の2つを `metadata.md` のとおりに作る（価格 300円 / 3,000円）
- [ ] ［自分］それぞれに **お試しオファー（1週間 無料）** を設定
- [ ] ［自分］RevenueCat でアプリを登録し、2つの製品を取りこむ。Entitlement を `plus` という名前で作って2つを紐づけ、Offering「current」に入れる
- [ ] ［自分］RevenueCat の **Apple 用公開 API キー**（`appl_` で始まる）をコピーし、`gohancho/index.html` の `revenueCatApiKey: ''` の '' の中に貼る
- [ ] ［自分］`cd ios-app && npm run sync` でアプリに反映（このキーが入ると、iPhone アプリ版だけ課金が有効になります。Web 版は無料のまま）

## 6. テスト購入（20分）

- [ ] ［自分］App Store Connect →「ユーザとアクセス」→「Sandbox」でテスト用アカウントを作る
- [ ] ［自分］iPhone の「設定」→「App Store」→「Sandbox アカウント」でサインイン
- [ ] ［自分］アプリで 1週間の主菜の鍵マークを押す → 年額を選ぶ → 購入できて、7日分が見えるようになるか確認
- [ ] ［自分］アプリを削除して入れ直し、設定 →「購入を復元」で戻るか確認

## 7. 申請（30分）

- [ ] ［自分］Xcode のメニュー「Product」→「Archive」→「Distribute App」→「App Store Connect」でアップロード
- [ ] ［自分］App Store Connect に `metadata.md` の文章を貼りつけ、スクリーンショット（6.9インチ）をアップロード
- [ ] ［自分］「App のプライバシー」を `metadata.md` のとおり回答
- [ ] ［自分］審査メモ（英語）を貼り、**サブスクリプションの2製品もこのバージョンと一緒に審査に出す**にチェック
- [ ] ［自分］「審査へ提出」

審査は通常1〜3日ほどです（時期により前後します。出典不明）。

## 公開前に必ず確認すること

- [ ] 「ごはん帖」という名前が商標登録されていないか、特許庁 J-PlatPat（https://www.j-platpat.inpit.go.jp/ ）で確認（第9類・第42類など）。不安なら弁理士に相談
- [ ] 自作レシピの文章が、特定の料理本やサイトの文章を写していないか
- [ ] アプリ名・説明文にほかの会社のアプリ名を入れていないか
