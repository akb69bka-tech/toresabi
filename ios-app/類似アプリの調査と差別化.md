# 類似アプリの調査と差別化（公開前の確認）

調査日: 2026年10月20日。目的は「模倣と見られうる点がないか」を公開前に確かめ、あれば直すこと。Web 検索で確認できた範囲の結果です（App Store の全件検索はできないため、申請前に App Store アプリで「ごはん帖」「献立」で一度検索して、同名・酷似のアイコンがないかを目で確認してください）。

## 2. 機能の重なり（主な競合）

| アプリ | 重なる点 | 違う点（ごはん帖の側） |
| --- | --- | --- |
| **me:new（ミーニュー）** | 日ごとに主菜・副菜・主食を自動提案、最長1週間、買い物リスト、LINE で家族に共有、アレルギー対応 | 献立を「お膳」の絵で見せる／作った記録から同じ料理を避ける／21か国の家庭料理／アカウント不要・端末内保存／手描きイラスト。me:new は運営会社の解散情報と最新更新の情報が食い違っており、現状は**わかりません** |
| **デリッシュキッチン**（カスタム献立） | 主菜・副菜・汁物をまとめて自動提案 | 動画レシピの大手。ごはん帖はレシピ閲覧より「毎日のお膳を決める」ことに特化 |
| **クラシル**（献立機能） | 主菜・副菜・汁物を選んで献立を組む、プレミアム月額480円 | 同上。価格はごはん帖の方が安い（380円） |
| **pecco（ぺっこ）** | 冷蔵庫の食材からレシピ提案 | pecco は食材管理に特化。ごはん帖は「あるもので作れる／あと1品で作れる」を献立に組みこむ |
| **味の素 未来献立** | 家族の好みで最大8日分 | 企業のレシピ資産が前提。ごはん帖は各国の家庭料理と端末内完結 |
| **meek** | 献立表・カレンダー、主食/主菜/副菜/汁物の分類 | 記録・表が中心。自動提案ではない |
| **Mise / AnyList / Plan to Eat / eMeals（海外）** | 週の献立と買い物リストの共有 | 「国を選ぶとその国の家庭料理で献立」という形のアプリは見つからず |

出典: [LDK 献立アプリ比較 2026](https://360life.shinyusha.co.jp/articles/-/45491)、[アプリブ 1週間の献立アプリ](https://app-liv.jp/foods/cooking/3069/)、[me:new の解説（appllio）](https://appllio.com/app-menew)、[me:new 使い方（good-apps）](https://good-apps.jp/media/app/17157)、[pecco](https://pecco.app/)、[meek](https://meek-cb617.web.app/)、[Mise](https://mise.cooking/)、[海外の献立アプリ比較 2026](https://www.foodieprep.ai/blog/meal-planning-apps-with-builtin-grocery-lists-a-2026-sidebyside-review)

結論: 「主菜・副菜・汁物の自動提案」「買い物リスト」「家族に共有」は**この分野の共通機能**で、どれか1つのアプリの特徴ではありません。模倣と見られるのは機能そのものより、**名前・キャッチコピー・見た目**が似ている場合です。

## 3. キャッチコピーの重なり → 直しました

| 直す前 | 問題 | 直した後 |
| --- | --- | --- |
| 「今日のごはん、もう悩まない。」（動画・ナレーション・プロモ文） | 「もう悩まない／迷わない」は紹介記事やタベリー等で使い古された定型句（[マイナビ農業](https://agri.mynavi.jp/2017_10_19_8712/)、[タベリーの紹介](https://www.teluru.jp/posts/493)） | **「今日のお膳、できました。」**（お膳はごはん帖だけの見せ方） |
| "Tonight's dinner, decided."（英語サブタイトル・動画） | 海外アプリ Mise が "Dinner Decided in Minutes" を使用（[Product Hunt](https://www.producthunt.com/p/mise-meal-plan-grocery-list/mise-meal-plan-and-grocery-list)）。"Dinner solved" 系も多数 | **"Your whole table, planned"**（サブタイトル）／ **"Your table, set for tonight."**（動画） |
| "Dinner, decided for you"（英語スクリーンショット1枚目） | 同上 | **"Your whole table, planned"** |
| 日本語サブタイトル「おまかせ献立・冷蔵庫の材料から」 | どの献立アプリにも当てはまる一般語 | **「お膳ごと、おまかせ献立」** |

## 4. 見た目の重なり

- 「お膳を真上から見た図に主菜・副菜・ご飯・汁物を配置する」見せ方は、検索した範囲では他の献立アプリに見つかりませんでした（配膳マナーの解説記事はありますが、アプリの UI としては確認できず）。これがごはん帖の最も固有な部分です。
- アイコン（「G」／「膳」の落款）はありふれた文字アイコンなので、他社の商標的なマークと重なる心配は小さいですが、同じ赤い角印のアイコンがないかは App Store で目視してください。
- 料理の絵はすべて自作のベクターイラスト（`tools/illustrations/`）で、他社の写真・絵は使っていません。

## 5. 残る注意

- レシピの文章は一般的な家庭料理の作り方で、特定の料理本やサイトの文章を写していませんが、**各国の料理名の表記**（例: 現地語の綴り）は一般名詞です。
- 「ごはん帖」の商標は未確認です。公開後に第三者が同名を商標登録すると名前を変える必要が出るため、余裕があれば自分で出願（第9類・第42類）も検討してください（費用の目安は特許庁の案内を参照。**出典不明**のため金額は書きません）。
