# LINE 作業日誌 — 使い方と設置手順

LINE に作業を送るとスプレッドシートに記録されて、毎晩、翌日の作業指示が LINE に届きます。

```
あなた → LINE「収穫 6 20ケース 3人」「剪定 西向き 2.5」
           ↓
Google スプレッドシート「記録」シートに 1 行ずつ追加
           ↓
毎晩 19 時：翌日の作業指示を LINE に送信（「明日」と送れば、いつでも返信します）
```

費用：Google 側は無料です。LINE 公式アカウントは無料プランで使えます（くわしくは下の「上限」）。

---

## 届く指示の例

```
【11/1(日) の作業指示】
天気: くもり  21℃/6℃  降水20%  風4m/s
⚠ 冷え込みの予報。暖房機・内張り（二重）の確認

■ やること
1. 📌 午後 部会
2. 収穫（この1週間 平均6.5h・21ケース / 昨年同時期 平均5.4h）
3. 薬散（前回 10/24(土) から8日。昨年のこの時期は約5日おき）
4. 剪定 西向き のつづき（直近3日で計6.5h）
5. 設備（暖房機ダクト 3日・チューブ水流し）（昨年この時期 3日・計8h）

■ そろそろ準備
・設備（二重ビニール張り）（昨年は7日後から）

■ 昨年の今ごろ（2025/10/29〜11/4）
・収穫 7日 計38h
・剪定（下葉かき 4日・東向き 4日） 7日 計23.5h
1日あたり 約11時間（昨年の同じ日付と比較）
```

指示の材料はこの 5 つです。

| 材料 | 中身 |
|---|---|
| 昨年の同じ時期 | 「昨年」シートの前後 3 日にやっていた作業。今作の定植日を入れると「定植から何日目」でそろえて比べます |
| 定期作業の間隔 | 薬散・除草剤・IPM は、昨年の同じ時期の間隔（前後 45 日の中央値）と、今作の前回からの日数を比べます |
| つづきの作業 | ここ 3 日の作業。「完了」を付けて送ると出なくなります |
| 予定 | LINE で「予定 11/5 午後部会」と送ったもの |
| 天気 | 場所を登録したときだけ表示します（Open-Meteo の無料予報） |

## LINE での送り方

| 送る文 | 結果 |
|---|---|
| `収穫 6 20ケース 3人` | 収穫 6時間・20ケース・午前3人 |
| `剪定 西向き 2.5` | 剪定（詳細：西向き）2.5時間 |
| `薬散2` | くっついていても読めます |
| `誘引 2回目 3時間 完了` | 完了を付けると翌日の「つづき」に出ません |
| `備考 午後部会` | その日の備考 |
| `昨日 収穫 5` | 昨日の分として記録 |
| `10/30` の行のあとに複数行 | まとめて 10/30 の分として記録 |

- 1 行に 1 作業。何行でもまとめて送れます
- 時間の書き方：`2` `2.5` `2h` `2時間半` `30分` `1時間30分`
- 全角数字でも大丈夫です
- 送ったあとに「今日の合計 ○h」が返ってきます。間違えたら `取消`

| コマンド | 結果 |
|---|---|
| `明日` | 明日の作業指示 |
| `今日` / `昨日` | その日の記録 |
| `今週` / `今月` / `先月` | 集計 |
| `取消` | 最後に送った記録を消す |
| `予定 11/5 午後部会` / `予定` | 予定を入れる／一覧 |
| `定植日 8/28` | 今作の定植日（昨年とそろえて比べるため。**最初に一度送ってください**） |
| `通知 20時` / `通知 オフ` | 毎晩の指示の時刻 |
| `場所 安芸市` / `場所 33.51 133.90` | 天気予報の場所 |
| `ヘルプ` | 使い方 |

## 設置手順（はじめの 1 回だけ。30 分ほど）

### 1. スプレッドシートに去年の日誌を貼る

1. Google ドライブの「LINE作業日誌」スプレッドシートを開く（なければ新しく作る）
2. 去年の Excel を開いて、シートを全部選択（Ctrl+A）してコピー
3. スプレッドシートの「昨年」シートの A1 をクリックして貼り付け

日付が 1 日の最初の行にしかない書き方や、月ごとの合計行が混ざっていても、そのままで読み込めます。

### 2. プログラムを入れる

1. スプレッドシートのメニュー「拡張機能 → Apps Script」
2. 最初からある `function myFunction() {}` を全部消して、`Code.gs` の中身を全部貼り付け
3. 保存（💾）

### 3. LINE 公式アカウントを作る

1. [LINE Official Account Manager](https://manager.line.biz/) でアカウントを作る（無料）
2. 「設定 → Messaging API」で「Messaging API を利用する」を押す（プロバイダーは自分の名前などで作成）
3. 「設定 → 応答設定」で
   - 応答メッセージ：**オフ**
   - Webhook：**オン**
4. [LINE Developers](https://developers.line.biz/console/) を開き、作ったチャネルの「Messaging API 設定」タブの一番下で「チャネルアクセストークン（長期）」を発行してコピー

### 4. 初期設定をする

1. スプレッドシートを再読み込みすると、メニューに「LINE作業日誌」が出ます
2. 「LINE作業日誌 → 初期設定」を押す
3. 初回は「承認が必要です」と出るので、自分の Google アカウントを選んで許可
   （「このアプリは確認されていません」と出たら「詳細 → （安全ではないページ）に移動」。作ったのは自分なので問題ありません）
4. もう一度「初期設定」を押して、順に入れる
   - チャネルアクセストークン（手順 3-4 でコピーしたもの）
   - 合言葉（家族や従業員が登録するときに使う。例：`なす2026`）
   - 通知の時刻（例：`19`）

### 5. LINE とつなぐ

1. Apps Script の画面右上「デプロイ → 新しいデプロイ」
2. 歯車 → 「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 「デプロイ」を押して、出てきた「ウェブアプリの URL」をコピー
4. LINE Developers の「Messaging API 設定 → Webhook URL」に貼って保存し、「Webhook の利用」をオン
5. 「検証」を押して「成功」と出れば OK（エラーが出ても、手順 6 で返事が来れば動いています）

### 6. 使い始める

1. LINE Developers の QR コードで公式アカウントを友だち追加
2. `登録 なす2026`（自分の合言葉）と送る → 「○○さんを登録しました」
3. `定植日 8/28`（今作の定植日）と送る
4. `場所 安芸市` と送る（天気がいらなければ省略）
5. `明日` と送って指示が返ってくれば完了です

家族や従業員も、友だち追加して `登録 合言葉` と送れば記録できます。入力した人の LINE の名前が「入力者」列に入ります。毎晩の指示は登録した全員に届きます。

## プログラムを直したとき

Apps Script で「デプロイ → デプロイを管理 → ✏（編集）→ バージョン：新バージョン → デプロイ」。
「新しいデプロイ」にすると URL が変わってしまい、LINE の Webhook URL を貼り直すことになります。

## 上限・注意

- **LINE の無料プランは「こちらから送るメッセージ」が月 200 通まで**（LINE 公式の料金案内による。改定されることがあるので、出典で最新を確認してください）。返信は数えません。毎晩の指示は「1 人 1 通 × 30 日」なので、**6 人までなら無料の範囲**です。7 人以上なら `通知 オフ` にして各自 `明日` と送るか、有料プランにしてください
  - 出典：LINEヤフー for Business「料金プラン」 https://www.lycbiz.com/jp/service/line-official-account/plan/
- 毎晩の指示は「指定した時の 0〜59 分のどこか」で届きます（19 時なら 19:00〜19:59。Apps Script の時刻トリガーの仕様）
  - 出典：Google Apps Script リファレンス ClockTriggerBuilder.atHour https://developers.google.com/apps-script/reference/script/clock-trigger-builder
- 合言葉を知らない人は記録できません。Apps Script は LINE の署名ヘッダーを読めないため、合言葉と登録メンバーで守っています。Webhook URL は人に教えないでください
- メンバーを外すとき：Apps Script「プロジェクトの設定 → スクリプト プロパティ」の `MEMBERS` から、その人の行を消す
- 記録はスプレッドシートを直接直しても大丈夫です（日付は 1 行ずつ入っていなくても読めます）
- 「月別集計」シートは毎晩自動で作り直します（メニューからも更新できます）

## 困ったとき

| 症状 | 確認すること |
|---|---|
| LINE に何を送っても返事がない | 応答設定で Webhook がオンか／Webhook URL が最新のデプロイの URL か／デプロイが「全員」になっているか |
| 「エラーが起きました」と返る | Apps Script の「実行数」でエラーの中身が見られます |
| 毎晩の指示が来ない | Apps Script の「トリガー」に `sendDailyPlan` があるか（なければ LINE で `通知 19時`） |
| 指示が昨年とずれている | `定植日 ○/○` を送ったか。「設定」シートの「昨年の定植日」も確認 |

## テスト

Node.js があれば、Google と LINE を偽物に差し替えた動作テストが動きます。
