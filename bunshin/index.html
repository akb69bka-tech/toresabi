分身の土台（プロフィール）

ここに書いたことが、分身の「性格」と「判断のしかた」になります。箇条書きでOK。あとから何度でも直せます。

質問に答えて、考え方を引き出す

「自分では当たり前」なことほど、分身には必要です。答えやすいものから。

分身を使う（Claude に渡す）

記録・回答・プロフィールをまとめて「分身の指示書」にします。Claude の「プロジェクト」の指示欄に貼ると、あなたの代わりに考える分身として使えます（手順は README）。

📬 Gmail

各記録の「📬 Gmail」ボタンで、メールの下書きが開きます（送信は自分で押す）。

ブリッジ経由で最近のメールを取り込む

💚 LINE

各記録の「💚 LINE」ボタンで LINE が開き、送る相手（自分だけのグループでも可）を選べます。

LINE のトーク画面 → メニュー → その他 → トーク履歴を送信 で書き出したテキストを選ぶか、貼り付け。

ブリッジ経由で LINE に通知する（Messaging API）

LINE Notify は 2025年3月に終了したため、通知は LINE 公式アカウント（Messaging API）＋ブリッジで行います。設定は README を参照。

📲 共有シートから受け取る

Android（Chrome）でホーム画面に追加すると、Gmail や LINE の「共有」から「分身ノート」を選んで、そのまま記録できます。iPhone の Safari は共有の受け取りに非対応のため、コピーして貼り付けてください。

🔗 ブリッジ（Google Apps Script）

自分の Google アカウントに置く小さな中継所です。記録のスプレッドシート保存、Gmail の取り込み、LINE 通知ができます。作り方は README。

💾 バックアップ

記録はこの端末のブラウザの中にだけ保存されます。機種変更や念のための保存に。
