# 分身ノート（自分の分身エージェントを育てるアプリ）

Claude などの AI に「自分の代わりに考えてもらう」には、自分の考え方・判断のくせ・取引先・言い回しが、文章になっている必要があります。
分身ノートは、それを毎日少しずつ **記録して集める** ためのスマホアプリです。HTML 1枚（`index.html`）で動き、ホーム画面に追加するとアプリとして使えます（PWA）。

公開 URL（GitHub Pages）: `https://akb69bka-tech.github.io/toresabi/bunshin/`

## できること

| 画面 | できること |
| --- | --- |
| ホーム | 分身の「濃さ」メーター、今日の質問（1日1問）、やること、最近の記録 |
| きろく | 話す／書くで記録。種類（アイデア・相談・判断・作業・知識・人・購入・販売・農薬・資材）は文章から自動判定。タグ・検索・結論の追記 |
| 分身 | プロフィール（大事にしていること・判断の軸・やらないこと・口ぐせ・取引先・資材）、43 問の「引き出し質問」、**分身の指示書**を書き出す、分身に相談（Claude を開く） |
| 連携 | Gmail（下書き送信・検索・貼り付け取り込み・ブリッジ取り込み）、LINE（共有・トーク履歴取り込み・ブリッジ通知）、共有シート受け取り、バックアップ |

記録はすべて **この端末のブラウザの中** に保存されます。クラウドには送りません（ブリッジを自分で設定した場合だけ、自分の Google スプレッドシートに送ります）。

## スマホに入れる

1. `https://akb69bka-tech.github.io/toresabi/bunshin/` を開く
2. ホーム画面に追加
   - iPhone: Safari の共有ボタン →「ホーム画面に追加」
   - Android: Chrome の︙ →「アプリをインストール」

## 使い方の流れ（おすすめ）

1. **分身タブ**で名前と仕事を入れる（これで分身に名前がつきます）
2. 毎日、ホームの **今日の質問** に 1 つ答える（音声でOK）
3. 思いついたこと・迷ったこと・決めたこと・注文したことを、右下の「＋」からその場で記録する
4. 2〜3 週間たったら **「分身の指示書を作る」** → コピー → Claude の **プロジェクト** を作り、「プロジェクトの指示（カスタム指示）」に貼る
5. そのプロジェクトの中で相談すると、Claude があなたの考え方で答えます。月に1回くらい指示書を作り直して貼り替えると、分身が育ちます

「分身に相談」ボタンは、プロフィールと直近の答えを短くまとめて Claude に渡します（文章が長いときはコピーされるので、貼り付けてください）。

## Gmail との連携

| 方法 | 必要なもの | できること |
| --- | --- | --- |
| 記録の「📬 Gmail」ボタン | なし | 記録をメールの下書きにして自分に送る（連携タブで宛先を設定） |
| Gmail を検索して開く | なし | 検索語を入れて Gmail を開く（例: `注文 農薬 newer_than:30d`） |
| 貼り付け取り込み | なし | メール本文をコピーして貼ると記録になる（件名・差出人を自動で拾う） |
| 共有シート（Android） | ホーム画面に追加 | Gmail の共有 →「分身ノート」でそのまま記録 |
| ブリッジ取り込み | 下の「ブリッジ」 | 最近のメール一覧をアプリ内に出して、ボタンで記録にする |

## LINE との連携

| 方法 | 必要なもの | できること |
| --- | --- | --- |
| 記録の「💚 LINE」ボタン | LINE アプリ | LINE が開いて送り先を選べる（自分だけのグループを作っておくとメモ代わりに） |
| トーク履歴の取り込み | なし | LINE のトーク → メニュー → その他 →「トーク履歴を送信」で出したテキストを読み込み、必要な発言だけ記録にする |
| 共有シート（Android） | ホーム画面に追加 | LINE のメッセージを長押し → 共有 →「分身ノート」 |
| ブリッジ通知 | 下の「ブリッジ」＋ LINE 公式アカウント | アプリから自分の LINE に通知を送る |

LINE Notify は 2025 年 3 月 31 日で終了したため、通知は LINE 公式アカウントの **Messaging API** を使います（無料プランは月 200 通まで）。
iPhone の Safari は「共有シートで受け取る」機能に対応していないため、iPhone ではコピー＆貼り付けか「LINE」「Gmail」ボタンを使ってください。

## ブリッジ（Google Apps Script）の作り方

ブリッジは、自分の Google アカウントに置く小さな中継所です。無料で、サーバーもいりません。

1. https://script.google.com/ を開き、「新しいプロジェクト」
2. `コード.gs` の中身を全部消して、`bridge.gs` の中身を貼る → 保存
3. 左の歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「プロパティを追加」
   - `TOKEN` … 好きな合言葉（長めに。例: `bunshin-2026-xxxxxxxx`）
   - LINE 通知も使うなら `LINE_CHANNEL_ACCESS_TOKEN` と `LINE_USER_ID`（下の手順）
4. エディタに戻り、関数の選択で `setupTest` を選んで「実行」→ 権限の承認（自分のアカウントのみ）
5. 「デプロイ」→「新しいデプロイ」→ 種類の選択で「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ 表示された **ウェブアプリの URL**（`/exec` で終わる）をコピー
6. 分身ノートの「連携」タブ →「ブリッジ」に URL と合言葉を入れて「接続テスト」

「記録をスプレッドシートに同期」を押すと、Google ドライブに「分身ノート_記録」というスプレッドシートができ、記録がたまっていきます（2回目以降は差分だけ送ります）。

### LINE 通知（Messaging API）の準備

1. https://developers.line.biz/console/ で プロバイダー → Messaging API チャネルを作る（LINE 公式アカウントができます）
2. チャネルの「Messaging API 設定」で **チャネルアクセストークン（長期）** を発行 → `LINE_CHANNEL_ACCESS_TOKEN`
3. 「チャネル基本設定」の下にある **あなたのユーザーID**（`U` で始まる）→ `LINE_USER_ID`
4. 作った公式アカウントを、自分の LINE で友だち追加する（QR コードがコンソールにあります）
5. `bridge.gs` を更新したら「デプロイを管理」→ 鉛筆 →「新バージョン」で再デプロイ

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・処理・質問リストをすべて含む） |
| `bridge.gs` | Google Apps Script のブリッジ（スプレッドシート保存・Gmail 取り込み・LINE 通知） |
| `manifest.webmanifest` | アプリ名・アイコン・共有シート受け取りの設定 |
| `sw.js` | オフラインで開けるようにするためのキャッシュ |
| `icon-*.png`, `apple-touch-icon.png` | ホーム画面のアイコン |
