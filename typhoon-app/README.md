# 台風進路予測システム（PWA）

Windy 風の画面で台風の進路・強度・自分の地点への影響を予測するアプリです。
スマートフォン／PC に **アプリとしてインストール** でき、一度開けばオフラインでも起動します。

> **重要**：本アプリの予測はすべて簡易モデルによる推定値です。防災上の判断は必ず
> 気象庁の発表（https://www.jma.go.jp/bosai/map.html）に従ってください。

## 1. 公開する（初回だけ・1分）

1. GitHub のリポジトリページ → **Settings → Pages**
2. **Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push すると `.github/workflows/pages.yml` が自動で配信します
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

インストール機能（ホーム画面に追加・オフライン起動）は **https** で配信されている必要があります。
GitHub Pages なら自動で https になります。ファイルを直接ダブルクリックして開いた場合も
通常の Web ページとしては動きますが、インストールとオフライン起動は使えません。

## 2. インストールする

| 端末 | 手順 |
|---|---|
| iPhone / iPad | Safari で開く → 共有ボタン → **ホーム画面に追加** |
| Android | Chrome で開く → 右上の「⬇ インストール」ボタン、またはメニュー → **アプリをインストール** |
| Windows / Mac | Chrome / Edge で開く → アドレスバー右端のインストールアイコン、または「⬇ インストール」ボタン |

## 3. 使い方

1. **📡 データ** から台風の実況位置を読み込む（気象庁から自動取得／CSV 貼り付け／サンプル）
2. 読み込むと自動で数値予報（ECMWF / GFS / ICON）の高層風を取得し、進路を計算します
   ヘッダーの表示が「数値予報 誘導」なら数値予報あり、「簡易外挿」なら通信できていません
3. 下のタイムラインを動かすと、中心位置・予報円・風の場が連動します
4. **📍 地点指定** で自宅や圃場を指定すると、最接近時刻・推定風速・暴風域に入る確率が出ます

## 4. オフラインでできること・できないこと

| できる | できない |
|---|---|
| アプリの起動、読み込み済みデータでの予測・タイムライン操作 | 新しい地図タイルの取得（見たことのある範囲はキャッシュから表示） |
| 最後に取得した数値予報での再計算 | 新しい数値予報・気象庁データの取得 |

## 5. 構成

```
typhoon-app/
├── index.html           アプリ本体（1ファイル）
├── manifest.webmanifest インストール用の情報（名前・アイコン・色）
├── sw.js                Service Worker（オフライン用キャッシュ）
├── icons/               アイコン（SVG / PNG）
└── vendor/leaflet/      地図ライブラリ Leaflet 1.9.4（BSD-2-Clause）
```

外部サービスへの通信：
- 地図タイル：CARTO（OpenStreetMap）／ Esri 衛星写真
- 数値予報・海面水温：Open-Meteo（台風周辺の格子座標のみ送信。指定地点は送信しません）
- 気象庁 JSON（自動取得を使った場合のみ）

## 6. 更新の反映

`sw.js` の `VERSION` を変えて push すると、次回起動時に「新しい版があります」と表示され、
タップで更新されます。
