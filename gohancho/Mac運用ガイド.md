# わが家のごはん帖 Mac 運用ガイド

MacBook にファイルを置いて、起動・レシピの追加・修正・スマホへの反映・バックアップをするための手順です。

---

## 1. 最初の準備（どちらか一つ）

### A. かんたん: ZIP を使う

1. 受け取った `gohancho.zip` をダブルクリックして展開する
2. できた `gohancho` フォルダを、置き場所（例: 「書類」）に移す

この方法は手軽ですが、変更の履歴が残らず、スマホへの反映も手作業になります。

### B. おすすめ: GitHub から取ってくる（履歴が残り、スマホへの反映も簡単）

1. 「ターミナル」を開く（Launchpad →「その他」→「ターミナル」）
2. 次を1行ずつ貼りつけて Enter

```bash
cd ~/Documents
git clone https://github.com/akb69bka-tech/toresabi.git
cd toresabi
git checkout claude/cooking-recipe-app
```

- 初回に「コマンドラインデベロッパツールをインストールしますか」と出たら「インストール」を押す（数分かかります）
- プルリクエストを main に取りこんだあとは `git checkout main` に切りかえる

アプリは `~/Documents/toresabi/gohancho/` に入ります。

---

## 2. 起動と終了

| やること | 方法 |
| --- | --- |
| 起動 | `gohancho` フォルダの **「Macで起動.command」をダブルクリック**。ブラウザで `http://localhost:8765/` が開きます |
| 終了 | 出てきたターミナルのウィンドウを閉じる（または Control + C） |

初回だけ「開発元が未確認のため開けません」と出ることがあります。そのときは **「Macで起動.command」を右クリック →「開く」→「開く」** を押してください。2回目からはダブルクリックで開けます。

- 起動用の仕組み（python3）が使えない Mac では、ファイルを直接開きます。その場合、オフライン機能とアプリ追加以外は同じように使えます
- Mac で付けた記録は Mac のブラウザに、スマホの記録はスマホに、別々に保存されます

## 3. 日々の運用

### レシピを足す（2通り）

**画面から（かんたん）**: 「記録」タブ →「わが家のレシピ」→「レシピを追加する」。そのブラウザだけに保存されます。

**ファイルに書き足す（家族全員のアプリに入る）**: `index.html` をテキストエディタ（「テキストエディット」なら「フォーマット」→「標準テキストにする」、または VS Code）で開き、`// ---- 主菜 ----` の下などに1行足します。

```js
R('butadaikon','豚バラ大根','和','主菜','煮',30,'豚バラ薄切り肉 150g|大根 1/3本|しょうが 1かけ?','だし 300ml・醤油 大さじ2・みりん 大さじ2・砂糖 大さじ1','大根は1cm幅のいちょう切りにする。|豚肉を炒め、大根を加えて油を回す。|だしと調味料を入れ、落としぶたで20分煮る。');
```

| 項目 | 書き方 |
| --- | --- |
| 1 ID | 半角英字。ほかと重ならない名前 |
| 2 料理名 | 画面に出る名前 |
| 3 ジャンル | `和` `洋` `中` `韓` `エスニック` |
| 4 種類 | `主菜` `副菜` `汁物` `ごはん` `麺` |
| 5 調理 | `煮` `炒` `焼` `揚` `和え` `汁` `炊` |
| 6 時間 | 分（数字） |
| 7 材料 | 「名前 分量」を `\|` で区切る。なくても作れるものは最後に `?` |
| 8 調味料 | そのまま表示される文 |
| 9 作り方 | 手順を `\|` で区切る |

保存したら、ブラウザで再読み込み（⌘ + R）すると反映されます。

### そのほかの調整

| やりたいこと | 場所 |
| --- | --- |
| 同じ料理を出さない日数 | 画面の「記録」タブ →「設定」 |
| 「ひと手間」の内容 | `index.html` の `const UPGRADES` |
| 写真を探す Wikipedia の記事名 | `index.html` の `const WIKI` |
| 励ましの言葉 | `index.html` の `const PRAISE` と `function greeting` |

## 4. 変更をスマホに反映する（1-B の方法で準備した場合）

先に GitHub の Settings → Pages を有効にしておきます（`README.md` の手順）。そのうえで、ターミナルで:

```bash
cd ~/Documents/toresabi
git add -A
git commit -m "レシピを追加"
git push
```

数分後、スマホのアプリを開き直すと新しい内容になります。

- アイコンを変えたときは、`sw.js` の1行目近くにある `gohancho-v1` を `gohancho-v2` のように数字を上げてください（古いアイコンが残るのを防ぎます）
- 初めての `git push` では GitHub へのログインを求められます

---

## 5. バックアップ

| 何を | 方法 |
| --- | --- |
| アプリ本体 | 1-B の方法なら GitHub に履歴ごと残っています。ZIP の場合はフォルダごと Time Machine や iCloud Drive にコピー |
| 献立の記録・お気に入り・常備品 | アプリの「記録」→「データの引っ越し・バックアップ」→「今のデータを表示してコピー」。メモ帳などに貼って保存 |
| 自分で撮った料理の写真 | 端末の中だけに保存されます。残したい写真は、撮った写真アプリ側でも保存しておいてください |

## 6. Mac 上で Claude に直してもらう

Mac に Claude Code（またはデスクトップ版 Claude の Code 機能）を入れると、このフォルダを開いた状態で「レシピを10品足して」「色を変えて」などと頼めます。

```bash
cd ~/Documents/toresabi
claude
```

## 7. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「Macで起動」が開けない | 右クリック →「開く」。それでも駄目ならターミナルで `chmod +x ~/Documents/toresabi/gohancho/Macで起動.command` |
| 「Address already in use」と出る | すでに起動しています。ブラウザで `http://localhost:8765/` を開く |
| 書き足したレシピが出ない | ブラウザで ⌘ + Shift + R（強制再読み込み）。それでも出なければ、行の `'` や `,` の抜けを確認 |
| 画面が真っ白になった | 直前に書き足した行に間違いがあります。Safari なら「開発」→「JavaScript コンソールを表示」で、赤字の行番号を確認 |
| 料理写真が出ない | Wikipedia につながらないか、その料理の写真が見つからない状態です。イラストで表示されます |
