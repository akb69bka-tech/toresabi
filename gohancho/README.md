# わが家のごはん帖（スマホアプリ版）

献立の提案・冷蔵庫の材料から料理さがし・定番のひとひねり・家事を励ます記録ができる料理アプリです。
HTML 1枚（`index.html`）で動き、スマホのホーム画面に追加するとアプリとして使えます（PWA）。

## スマホに入れる手順

1. GitHub の **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main`（フォルダは `/ (root)`）にして保存する
2. 数分後、`https://akb69bka-tech.github.io/toresabi/gohancho/` をスマホで開く
3. ホーム画面に追加する
   - iPhone: Safari の共有ボタン →「ホーム画面に追加」
   - Android: Chrome の︙メニュー →「アプリをインストール」

一度開けば、電波がなくても献立・レシピ・記録が使えます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（レシピデータ・画面・処理をすべて含む） |
| `manifest.webmanifest` | アプリ名・アイコン・表示方法 |
| `sw.js` | オフラインで開けるようにするためのキャッシュ |
| `icon-*.png`, `apple-touch-icon.png` | ホーム画面のアイコン |

## 写真と動画

- 料理写真は、アプリを開いた端末が Wikipedia / Wikimedia Commons から読み込みます。撮影者・ライセンス・出典を写真に表示します。写真がない料理は自動で描くイラストになります。
- 「作った料理を撮って登録」で、自分で作った料理の写真をその料理の写真にできます（端末の中にだけ保存）。
- 作り方の動画は、YouTube の検索結果を開くボタンです。動画そのものはアプリに入れていません。
- 記録は端末のブラウザの中に保存されます。機種変更のときは「記録」画面のバックアップを使ってください（自分で撮った写真はバックアップに入りません）。
